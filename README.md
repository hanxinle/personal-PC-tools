# 我的工作流工具(自研版)

## 项目1：小猫闹钟（H5）

<img src="doc/cat_clock.png" alt="小猫闹钟截图" width="400">

**小猫闹钟** — 一只住在浏览器里、负责叫你起床（或者起来吃饭、开会、摸鱼）的小猫咪。

它很乖，只要一个 HTML 文件就能跑，不用安装不用配环境。你可以让它同时记好多个闹钟，每个都能换上你喜欢的铃声（默认自带几首，也支持上传自己的宝藏音乐）。到点它会蹦出来一个弹窗，配上一张可爱的 GIF，赖床？不存在的。

深色渐变背景加上毛玻璃卡片，颜值在线；时间可以用滚轮搓、用键盘调、或者直接打字输入，怎么顺手怎么来。闹钟响过之后会变成「已响铃」状态乖乖待在列表里，随时查看自己今天又准时了几次。



## 项目2：PC 原生闹钟

**PC 原生闹钟** — 一只住在桌面上的大猫咪，用 C++ 和 Qt 锻造而成，和浏览器里那只轻飘飘的 H5 小猫是亲兄弟，但脾气更猛，需要自己编译才能用。这是项目1 的最初版，用起来相对麻烦，推荐项目1，只需浏览器就可以使用。



## 项目3：拒绝锁屏

**拒绝锁屏** — 专门针对一段时间无操作后强制锁屏的 PC，这也是一款 PC 原生 C++ 软件。

启动后缩在一边即可，窗口里还有一只循环播放的 GIF 小猫动画陪你。



## 项目4：小猫闹钟桌面封装

**小猫闹钟桌面封装** — 给项目1 的 H5 小猫闹钟套上了一个桌面外壳，用 C++ 和 Qt WebView 写成，直接调用系统原生的 Edge WebView2 引擎加载同一个 HTML 文件。浏览器里是什么效果，桌面窗口里就是什么效果，但不用先开浏览器，双击即用。



## 项目5：桌面宠物猫

**桌面宠物猫** — 把一张猫咪照片变成住在 Windows 桌面上的宠物：无边框透明窗口、置顶显示，左键按住可以拖着满屏幕跑，右键菜单能点播墨镜、喝水、摇头、睡觉四个动作，待机时它还会每几秒随机自娱自乐一下。

它由 Python + PyQt5 写成：先跑 `python gen_assets.py`，脚本会用 rembg 给照片自动抠图，再用 Pillow 合成全部动作序列帧；之后 `python pet.py` 就能让猫咪上桌。想分享给没有 Python 环境的朋友，也可以用 PyInstaller 打包成单文件 exe，双击即用。
